# APSプレートタイマー

APSカップ(エアソフトガン精密射撃競技)ハンドガン部門「プレート」種目を自宅で練習するためのWebアプリです。
URLを開くだけで使えます。アカウント登録・サーバー通信・アクセス解析はありません。記録は端末の中だけに保存されます。

公開URL: https://bond-aps.github.io/plate-timer/

## できること

- **音声タイマー**: 競技の実音声(「プレート、スタンバイ、レディー」→ 開始ブザー → 3.0秒 → 終了ブザー)を15枚ぶん自動で流します。冒頭・5枚ごと・終了には審判の指示音声が入ります(審判の実録音 / AI音声 男性 / AI音声 女性 から選択)。
- **反応時間の計測**: スマホのマイクで発砲音を拾い、開始ブザーから何秒後に撃ったかを枚ごとに計測します。
- **履歴**: 当たり/外れと反応時間を保存し、平均・ばらつき・3秒超過枚数、セット別の推移、枚別(1〜15)の平均を振り返れます。CSV書き出し・JSONバックアップつき。
- **PWA**: ホーム画面に追加すればアプリのように起動でき、オフラインでも動きます。

## 使い方(iPhone)

1. Safariで公開URLを開く。
2. 共有ボタン → 「ホーム画面に追加」(Androidは Chrome のメニュー → 「ホーム画面に追加」)。
3. 初回は「マイクを許可して計測する」を押してマイクを許可。
4. 端末を撃つ場所の近く(1〜2m)に置き、音量を上げて「開始」。
5. 15枚終わったら当たった的をタップして「保存」。履歴タブで振り返り。

詳しい使い方と注意点はアプリ内の「設定 > 使い方」にあります。

## 動作環境

iPhone Safari(iOS 17以上)を最優先に作っています。Android Chrome、Mac/PCのブラウザでも動きます。

## 既知の制約

- 反応時間が **2.95〜3.30秒** の発砲は終了ブザーの音と重なるため計測できません(「−」と表示)。
- タイマー中に画面ロックで音声が止まった場合は「中断しました」と表示されます。もう一度「開始」を押してください。

## 開発

ビルド工程も依存パッケージもありません(HTML/CSS/JS/音声の静的ファイルのみ、ES modules)。

```bash
python3 -m http.server 8765 --bind 127.0.0.1   # http://localhost:8765/ で開く
npm test                                        # Node検算(AudioContext復旧・録音解析・集計/CSV)
```

構成・iPhone対策の要点・デプロイ手順は [CLAUDE.md](CLAUDE.md) を参照してください。
